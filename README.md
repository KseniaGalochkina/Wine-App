# Рекомендации вин: демо-приложение

Streamlit-приложение для сомелье сервиса: оценка одного вина, метрики модели
при выбранном пороге, пакетное предсказание по CSV и коэффициенты модели.

## Запуск

Версия Python: 3.12.10

    python -m venv venv
    venv\Scripts\activate        (Windows)   /   source venv/bin/activate (macOS, Linux)
    pip install -r requirements.txt
    streamlit run app.py

## Файлы

- `app.py` - приложение;
- `model.joblib` - пайплайн (StandardScaler + LogisticRegression), обучен на X_train;
- `config.json` - порог по умолчанию (t_F1 = 0.268.., подбирался на валидации);
- `test.csv` - тестовая выборка;
- `requirements.txt` - версии библиотек.

## Кэширование (задание 4.5)

Модель загружается через st.cache_resource, потому что это тяжёлый объект, который нужно создать один раз и использовать как есть, без копирования, для всех запусков и пользователей. Таблицы и вероятности кэшируются через st.cache_data, потому что это данные, и каждый вызов получает их копию, которую безопасно изменять. Если вызывать joblib.load без декоратора, модель будет читаться с диска при каждом движении слайдера или нажатии кнопки, и приложение станет медленным.
